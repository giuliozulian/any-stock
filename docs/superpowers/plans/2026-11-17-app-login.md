# Login con Supabase Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mettere tutta l'app (pagine e API) dietro un login con email e password su Supabase Auth, per un solo utente, lasciando fuori solo `/login`, i file statici, i cron, `widget` e `calendar` (questi ultimi a token obbligatorio).

**Architecture:** `proxy.ts` rinnova la sessione Supabase (cookie httpOnly via `@supabase/ssr`) e reindirizza le pagine a `/login`. Ogni route chiama `requireUser()` e ogni pagina passa da `<AuthGate>` dentro il suo `Suspense`: due controlli indipendenti, verificati sul server di Supabase con `auth.getUser()`. Configurazione mancante in produzione = 503, mai app aperta.

**Tech Stack:** Next.js 16 (App Router, `proxy.ts`, Cache Components), TypeScript, `@supabase/ssr` + `@supabase/supabase-js`, vitest + Testing Library, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-17-app-login-design.md`. Deviazioni intenzionali:
1. **Il proxy non blocca `/api`**: rinnova solo la sessione e lascia passare; ogni handler applica `requireUser()`. Motivo: `/api/scanner` e `/api/scanner/step` devono accettare `Bearer CRON_SECRET` dal workflow, e il proxy le fermerebbe prima. Un test statico (Task 4) garantisce che nessuna route protetta venga dimenticata.
2. Le funzioni pure di configurazione stanno in `lib/auth-config.ts` (senza `next/headers`), così il proxy non importa codice che legge i cookie; `lib/auth.ts` le riesporta.
3. I test esistenti non simulano `requireUser`: `vitest.config.ts` imposta `AUTH_DISABLED=1` (vale perché `NODE_ENV` è `test`), e solo i test di autenticazione lo azzerano con `vi.stubEnv`.
4. `requireUserOrRedirect` vive in un componente `AuthGate` dentro il `Suspense` di ogni pagina, perché `cacheComponents: true` vieta di leggere i cookie fuori da un `Suspense`. `requireUserOrRedirect(path)` riceve il percorso da ricordare dopo il login.
5. `scripts/create-user.mjs` va lanciato dal terminale dell'utente (serve un terminale interattivo per nascondere la password), non con `!`.

`lib/safe-next.ts`:

```ts
const MAX_LENGTH = 2000

// Where to send the user after login: only paths inside this site. Anything else (another host, a scheme, a protocol-relative
// "//host", backslashes that browsers read as slashes, control characters) falls back to the home page. /login itself is refused too:
// it would send a signed-in user back to the login page forever.
export function safeNext(value: string | null | undefined): string {
  if (!value || value.length > MAX_LENGTH) return '/'
  if (!value.startsWith('/') || value.startsWith('//') || value.includes('\\')) return '/'
  if (/[\u0000-\u001f\u007f]/.test(value)) return '/'
  if (/^\/login(?:[/?#]|$)/i.test(value)) return '/'
  return value
}
```

`lib/safe-equal.ts`:

```ts
import { createHash, timingSafeEqual } from 'node:crypto'

// Constant-time comparison of two secrets. Hashing first makes the comparison independent of the lengths.
// An empty value never matches, so an unset secret cannot be satisfied by an empty input.
export function safeEqual(a: string, b: string): boolean {
  if (!a || !b) return false
  const ha = createHash('sha256').update(a).digest()
  const hb = createHash('sha256').update(b).digest()
  return timingSafeEqual(ha, hb)
}
```

`lib/auth-config.ts`:

```ts
let warned = false

export function resetAuthWarning(): void {
  warned = false
}

// AUTH_DISABLED opens the app for local development only: in production it is ignored, so it can never open a deployed app.
export function authDisabled(): boolean {
  return process.env.AUTH_DISABLED === '1' && process.env.NODE_ENV !== 'production'
}

export function warnAuthDisabled(): void {
  if (warned) return
  warned = true
  console.warn('AUTH_DISABLED=1: the app is open to everyone. Use it only on your own machine.')
}

export function authConfigured(): boolean {
  return Boolean(process.env.NEXT_PUBLIC_SUPABASE_URL && process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY && process.env.AUTH_ALLOWED_EMAIL)
}
```

```ts
import { redirect } from 'next/navigation'
import { authConfigured, authDisabled, isAllowedEmail, warnAuthDisabled } from '@/lib/auth-config'
import { safeEqual } from '@/lib/safe-equal'
import { createSupabaseServerClient } from '@/lib/supabase/server'

export { authConfigured, authDisabled, isAllowedEmail } from '@/lib/auth-config'

export interface AuthedUser {
  id: string
  email: string
}

export type AuthResult = { ok: true } | { ok: false; response: Response }

async function fetchUser(): Promise<AuthedUser | null> {
  if (authDisabled()) {
    warnAuthDisabled()
    return { id: 'dev', email: 'dev@local' }
  }
  if (!authConfigured()) return null
  try {
    const supabase = await createSupabaseServerClient()
    // getUser() asks the Supabase server to validate the token; getSession() would trust the cookie as it is.
    const { data, error } = await supabase.auth.getUser()
    if (error || !data.user || !data.user.email || !isAllowedEmail(data.user.email)) return null
    return { id: data.user.id, email: data.user.email }
  } catch (err) {
    console.error('Auth check failed:', err instanceof Error ? err.message : String(err))
    return null
  }
}

// One check per request: layout and page share the result.
export const getAuthedUser = cache(fetchUser)

function hasCronSecret(request: Request): boolean {
  const secret = process.env.CRON_SECRET
  const header = request.headers.get('authorization')
  return Boolean(secret && header && safeEqual(header, `Bearer ${secret}`))
}

// First line of every protected route handler. `allowCron` also accepts `Authorization: Bearer <CRON_SECRET>` for the routes
// the evening workflow calls.
export async function requireUser(request?: Request, options: { allowCron?: boolean } = {}): Promise<AuthResult> {
  if (authDisabled()) {
    warnAuthDisabled()
    return { ok: true }
  }
  if (!authConfigured()) return { ok: false, response: Response.json({ error: 'Auth not configured' }, { status: 503 }) }
  if (options.allowCron && request && hasCronSecret(request)) return { ok: true }
  if (!(await getAuthedUser())) return { ok: false, response: Response.json({ error: 'Unauthorized' }, { status: 401 }) }
  return { ok: true }
}

// For pages. `path` is where to come back to after logging in.
export async function requireUserOrRedirect(path = '/'): Promise<void> {
  if (authDisabled()) {
    warnAuthDisabled()
    return
  }
  if (!authConfigured()) redirect('/login?error=config')
  if (!(await getAuthedUser())) redirect(`/login?next=${encodeURIComponent(path)}`)
}
```

```ts
import { createServerClient } from '@supabase/ssr'
import { NextResponse, type NextRequest } from 'next/server'

// Refreshes the Supabase session on the way in: if the access token was renewed, the new cookies are set on both the request
// (so the page sees them) and the response (so the browser stores them). Returns the validated user, or null.
export async function updateSession(request: NextRequest): Promise<{ response: NextResponse; user: { email?: string | null } | null }> {
  let response = NextResponse.next({ request })
  const supabase = createServerClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!, {
    cookies: {
      getAll: () => request.cookies.getAll(),
      setAll: (cookiesToSet) => {
        for (const { name, value } of cookiesToSet) request.cookies.set(name, value)
        response = NextResponse.next({ request })
        for (const { name, value, options } of cookiesToSet) response.cookies.set(name, value, options)
      },
    },
  })
  // getUser() validates the token with the Supabase server; getSession() would trust the cookie.
  const { data } = await supabase.auth.getUser()
  return { response, user: data.user }
}
```

```ts
import { NextResponse, type NextRequest } from 'next/server'
import { authConfigured, authDisabled, isAllowedEmail } from '@/lib/auth-config'
import { updateSession } from '@/lib/supabase/proxy'

function toLogin(request: NextRequest, search: string): NextResponse {
  const url = request.nextUrl.clone()
  url.pathname = '/login'
  url.search = search
  return NextResponse.redirect(url)
}

// First, quick gate for pages. It is not the only check: every route handler calls requireUser() and every page goes through
// <AuthGate>. /api is not blocked here because the scanner routes also accept the cron secret, which only their handlers know.
export async function proxy(request: NextRequest) {
  if (authDisabled()) return NextResponse.next()

  const { pathname, search } = request.nextUrl
  const isApi = pathname.startsWith('/api/')

  if (!authConfigured()) return isApi ? NextResponse.next() : toLogin(request, '?error=config')

  let session: Awaited<ReturnType<typeof updateSession>>
  try {
    session = await updateSession(request)
  } catch {
    // Supabase unreachable: fail closed for pages, and let the handlers answer for the API.
    return isApi ? NextResponse.next() : toLogin(request, `?next=${encodeURIComponent(pathname + search)}`)
  }

  if (isApi) return session.response
  if (session.user && isAllowedEmail(session.user.email)) return session.response
  return toLogin(request, `?next=${encodeURIComponent(pathname + search)}`)
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico|icon.svg|manifest.webmanifest|pwa-icon|login|api/cron|api/widget|api/calendar).*)'],
}
```

```ts
'use server'

import { redirect } from 'next/navigation'
import { authConfigured, isAllowedEmail } from '@/lib/auth-config'
import { safeNext } from '@/lib/safe-next'
import { createSupabaseServerClient } from '@/lib/supabase/server'
import type { LoginState } from './state'

// One message for a wrong password and for an account that is not the allowed one: nothing tells which of the two happened.
const WRONG = 'Email o password errati.'

export async function login(_previous: LoginState, formData: FormData): Promise<LoginState> {
  const email = String(formData.get('email') ?? '').trim()
  const password = String(formData.get('password') ?? '')
  const next = safeNext(String(formData.get('next') ?? ''))
  if (!email || !password) return { error: 'Inserisci email e password.' }
  if (!authConfigured()) return { error: 'Accesso non configurato.' }

  try {
    const supabase = await createSupabaseServerClient()
    const { data, error } = await supabase.auth.signInWithPassword({ email, password })
    if (error || !data.user) return { error: WRONG }
    if (!isAllowedEmail(data.user.email)) {
      await supabase.auth.signOut()
      return { error: WRONG }
    }
  } catch {
    return { error: 'Non riesco ad accedere, riprova tra poco.' }
  }
  // Outside the try: redirect() works by throwing, and the catch would swallow it.
  redirect(next)
}

export async function logout(): Promise<void> {
  if (authConfigured()) {
    try {
      const supabase = await createSupabaseServerClient()
      await supabase.auth.signOut()
    } catch {
      // Leaving anyway: the login page is where a signed-out visitor belongs.
    }
  }
  redirect('/login')
}
```

```tsx
import { connection } from 'next/server'
import { requireUserOrRedirect } from '@/lib/auth'

// Second line of defence behind proxy.ts: a page renders its data only after the session has been checked again.
// It sits inside the page's <Suspense> because Cache Components do not allow reading cookies outside one.
export async function AuthGate({ path, children }: { path: string; children: React.ReactNode }) {
  await connection()
  await requireUserOrRedirect(path)
  return <>{children}</>
}
```

```python
BLOCK = re.compile(r'(<Suspense fallback=\{[^\n]*\}>\n)(\s*)(<[A-Za-z]+ [^\n]*/>)(\n\s*</Suspense>)')

for path, route in PAGES.items():

    assert sep, path
    assert '<AuthGate' not in tail, path
    new_tail, n = BLOCK.subn(lambda m: f'{m.group(1)}{m.group(2)}<AuthGate path="{route}">\n{m.group(2)}  {m.group(3)}\n{m.group(2)}</AuthGate>{m.group(4)}', tail, count=1)
    assert n == 1, (path, 'Suspense block not found')
    last = None
    for m in re.finditer(r'^import .*\n', head, re.M):
        last = m
    head = head[:last.end()] + IMPORT + head[last.end():]
    open(path, 'w').write(head + sep + new_tail)
    print('wrapped', path)
```

- [ ] **Step 4: Write the user-creation script** — crea `scripts/create-user.mjs`:

```js
// Creates the single user of the app in Supabase Auth, with the email already confirmed.
// Run it from your own terminal (it needs an interactive terminal to hide the password):  node scripts/create-user.mjs
// Reads NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY and AUTH_ALLOWED_EMAIL from .env.local.
// The service role key never leaves this machine; nothing secret is printed.
import { config } from 'dotenv'

config({ path: '.env.local' })

export async function createUser({ url, serviceKey, email, password, fetchImpl = fetch }) {
  const res = await fetchImpl(`${url.replace(/\/+$/, '')}/auth/v1/admin/users`, {
    method: 'POST',
    headers: { apikey: serviceKey, Authorization: `Bearer ${serviceKey}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password, email_confirm: true }),
  })
  if (res.ok) return { status: 'created' }
  const body = await res.json().catch(() => ({}))
  if (res.status === 422 && /already|registered|exists/i.test(`${body.msg ?? ''} ${body.error_code ?? ''} ${body.message ?? ''}`)) return { status: 'exists' }
  return { status: 'failed', httpStatus: res.status }
}

async function askHidden(label) {
  if (process.env.NEW_USER_PASSWORD) return process.env.NEW_USER_PASSWORD
  if (!process.stdin.isTTY) throw new Error('Run this script from an interactive terminal so the password can be typed without being shown.')
  process.stdout.write(label)
  const stdin = process.stdin
  stdin.setRawMode(true)
  stdin.resume()
  stdin.setEncoding('utf8')
  let value = ''
  return new Promise((resolve) => {
    stdin.on('data', function onData(chunk) {
      for (const c of chunk) {
        if (c === '\r' || c === '\n' || c === '\u0004') {
          stdin.setRawMode(false)
          stdin.pause()
          stdin.removeListener('data', onData)
          process.stdout.write('\n')
          return resolve(value)
        }
        if (c === '\u0003') process.exit(130)
        if (c === '\u007f') value = value.slice(0, -1)
        else value += c
      }
    })
  })
}

async function main() {
  const url = process.env.NEXT_PUBLIC_SUPABASE_URL
  const serviceKey = process.env.SUPABASE_SERVICE_ROLE_KEY
  const email = process.env.AUTH_ALLOWED_EMAIL?.trim()
  const missing = [['NEXT_PUBLIC_SUPABASE_URL', url], ['SUPABASE_SERVICE_ROLE_KEY', serviceKey], ['AUTH_ALLOWED_EMAIL', email]].filter(([, v]) => !v).map(([k]) => k)
  if (missing.length > 0) {
    console.error(`Missing in .env.local: ${missing.join(', ')}`)
    process.exit(1)
  }
  const password = await askHidden(`Password for ${email} (min 8 characters): `)
  if (password.length < 8) {
    console.error('The password must have at least 8 characters.')
    process.exit(1)
  }
  const result = await createUser({ url, serviceKey, email, password })
  if (result.status === 'created') console.log(`User ${email} created. You can now log in.`)
  else if (result.status === 'exists') console.log(`User ${email} already exists: nothing changed. Reset the password from the Supabase dashboard if you forgot it.`)
  else {
    console.error(`Supabase refused the request (HTTP ${result.httpStatus}). Check the URL and the service role key.`)
    process.exit(1)
  }
}

if (import.meta.url === `file://${process.argv[1]}`) {
  main().catch((err) => {
    console.error(err instanceof Error ? err.message : String(err))
    process.exit(1)
  })
}
```
